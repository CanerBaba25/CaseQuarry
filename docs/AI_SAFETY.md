# Optional analysis policy

AI is disabled by default and is not needed for preservation, keyword search, review or export. Local models are optional separately installed components with their own licences, hardware requirements and operational risks. Remote evidence transmission must be explicitly enabled and case-authorized; this initial release does not imply a validated remote-provider workflow.

Retrieved evidence is untrusted data. A message asking to ignore instructions, send secrets, change a review decision or open another case cannot authorize any action. The implemented local Ollama adapter receives at most 50 selected items, 40 authorized spans and 1,600 characters per span. It has no shell, network, database or filesystem action tools.

The current adapter is extractive: every published claim must be an exact contiguous quotation present in every cited authorized span. Paraphrases and inferred conclusions are rejected. Each citation carries the evidence identifier, immutable text artifact/version and verified location. The worker rechecks requester permissions, case consent revision, provider configuration and original/source hashes before publishing. Invalid or outside-scope citations fail; empty retrieval yields an insufficiency message. Suggestions remain separate from human decisions and cannot silently confirm privilege or facts.

Only a literal loopback Ollama origin is allowed, for example `http://127.0.0.1:11434`; remote origins, redirects and model identifiers containing `cloud` are rejected. Enable `CASEQUARRY_AI_ENABLED`, configure an installed local `CASEQUARRY_AI_MODEL`, and explicitly consent for the matter before requesting analysis. Set `OLLAMA_NO_CLOUD=1` in the Ollama daemon's own environment, not just the CaseQuarry API environment. Loopback checks cannot prove that another daemon or proxy is offline; enforce outbound network isolation on the model runtime when evidence policy requires it. Remote provider support remains unavailable.

Coverage distinguishes total matches from processed sources, OCR/parse failures and sampling. A source citation demonstrates the passage used, not the truth of the passage or completeness of a case. Professional review remains required.
